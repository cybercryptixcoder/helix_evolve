Helix

An evolutionary loop that writes programs to solve hard problems, and keeps making progress over many generations.
Evolutionary loops only go wide: random variations of the best code→I added a loop that goes deep: a researcher that tests one idea at a time
Every generation starts fresh, shown only the best programs→Continuity: the system keeps building on what it already learned
A context window can't hold everything that was tried→Atlas: a memory the agent navigates, opening only what it needs

The problem I tested it on

The second autocorrelation inequality: a known open problem in mathematics (analysis).
Type: optimisation. Find a function that makes a score as high as possible. The true maximum is unknown.
A solution: a list of numbers (a step function), plus the program that found it.
Why this problem
Every solution is a proof : its score is a certified bound, so nothing can be faked
Scoring is exact and cheap : no LLM judges the results
It is open-ended : there is always room to climb, so I can see whether progress continues
There is a public record : human mathematicians and AI systems (AlphaEvolve) to compare against
