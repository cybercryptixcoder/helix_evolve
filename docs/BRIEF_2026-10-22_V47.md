# Brief, October 22, 2026 (evening): the false ceiling, and v4.7

## 1. The ask, in one paragraph

Shreyas asked whether anything in the setup makes Helix try less hard the better it does (a false ceiling), from
v4's 150-generation atlas-s1 run (`results/v4cont/atlas-s1`) and from the VRP runs. The analysis
(`docs/V4_CEILING.md`) found four mechanisms:
- new ideas erased by the fallback to the start;
- every idea judged against the champion at once;
- a findings map made entirely of failures;
- 1e-9 "gains".

He then asked for a new version of v4 that implements every fix: a variant of v4, not a new architecture, meant
to be a strict improvement, implemented cleanly, tested, ready for a job, and pushed. That is v4.7.

## 2. Notes and decisions

- **Name and place.** v4.7, in `helix47/`. It subclasses helix4 and changes nothing in it. The condition name is
  `v47`.
- **Strict improvement.** Breadth turns on only while a run is stalled; v4.5's always-on portfolio started slower
  than v4 (`docs/V5_RESULTS.md`). So while climbing, v4.7 runs v4's generation, with better measurement and display.
- **The model.** DeepSeek V4.1 Flash is also the model behind Hermes, which calls every flat curve a ceiling. v4.7
  doesn't argue with that disposition. Code assigns the step and challenger slots, and the challenger's planner never
  sees the plateau.
- **No outside information.** No record values and no "better is known to exist". The only stated room is the bound
  the problem text already gives (R ≤ 1).
- **The VRP program cut-off** (base programs clipped at 45,000 characters) was fixed in the private helix_vrp package,
  which is not in this repo. v4 had the same bug at 12,000 characters (67 of 420 late programs), fixed in v4.7.
- **The job.** v4.7 and plain v4 side by side, 3 seeds each, 30 generations, waiting for the VRP job (running until
  about 7 AM on October 23) to finish.

### October 23, 00:21: the redesign
Shreyas pointed out that the first draft (an always-on set of fixes plus, while stalled, a step slot and a challenger
line) was in effect a third loop: the main deep loop still polished the stalled champion and stayed pessimistic.
He was right. v4.7 now organises the main deep loop in lines:
- each line is judged against its own previous generations;
- code closes a stalled line and opens new ones (from an alternative, another branch, or fresh);
- slots follow progress;
- the planner sees only the active lines and is never asked whether a construction is saturated.

The step slot and the challenger are gone. He also stopped the VRP v4 job at generation 41–42 (flat) and asked for
v4.7 on the VRP too. Both jobs are queued: VRP v4.7 first, then the ac2 job.
